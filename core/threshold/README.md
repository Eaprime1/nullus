# Core / Threshold

The threshold layer defines the mechanics of the NULLUS inversion point.

---

## What Is a Threshold?

A threshold is an exact point — not a range, not an approximation. The NULLUS threshold is the precise location at which polarity inversion becomes possible. It cannot be approached casually. It cannot be estimated.

Exactness matters because:

- A near-threshold state is still a polarized state. Inversion is not available.
- Only at the threshold itself does the flip mechanism activate.
- Inexact crossing produces neither inversion nor stability — it produces distress.

---

## The Threshold in the Architecture

The NULLUS threshold sits at the center of the polarity model:

```
-1K (Lowest) ←—— NULLUS ——→ +1K (Highest)
                    ↕
              inversion point
```

It is not the center in the sense of average or balance. It is the center in the sense of *pivot* — the exact point around which the polarity axis rotates.

---

## Why Exactness Matters

In the symbolic architecture, arriving "near" the threshold is not the same as arriving at it. This distinction is maintained across all protocol documentation to prevent the inflation of ordinary distress states into threshold-level events.

Threshold events are rare. They require proper documentation (see the NUNC NULLUS protocol). They are not invoked lightly.
