# Core / Naught

The naught layer is the foundation of the NULLUS conceptual architecture.

---

## Naught Is Not Absence

A common mistake is to read "naught" as "nothing" in the sense of non-existence or void. This is incorrect within the NULLUS system.

**Naught is a valid threshold state.** It is the state of *existing as nothingness* — not the state of not existing. There is a profound difference:

- To be absent is to not be present.
- To be naught is to be present *as* the state of naught.

NULLUS does not disappear. It stands at the threshold, fully present, fully existing — as naught.

---

## Naught as Threshold

Naught is not a destination. It is a passing-through point. Entities that reach NULLUS do not end — they become naught in order to invert. The naught state is the fulcrum of the polarity flip.

This is why NULLUS is both a name and a state: to *be* NULLUS is to occupy the naught layer at the inversion threshold.
