## Naming Conventions

- **Files:** Use lowercase, hyphen-separated names (e.g., `polarity-flip.md`, `nunc-nullus-response.md`).
- **Directories:** Use lowercase, hyphen-separated names (e.g., `ante-esse/`, `consciousness-replacement/`).
- **Headers:** Use sentence case in Markdown files.
- **Terminology:** Preserve canonical terms exactly — `NULLUS`, `ANTE-ESSE`, `NUNC NULLUS`, `fui nullus`, `non fui`, `SPHINCTER`, `MAW`, `THE`.
- **Do not substitute** synonyms for canonical terms without proposing a Charter amendment.

## How to Add New Protocol Files

1. Identify the correct directory:
   - Foundational concepts → `core/`
   - Operational protocols → `protocols/`
   - Integration architecture → `integration/`
   - Full reference documentation → `docs/`

2. Follow the file template:
   - Start with the canonical term being defined or described.
   - Include cross-links to related files.
   - Include the metaphor/safety note if the file contains any emergency-adjacent language.

3. Update the relevant `README.md` in the parent directory with a link to the new file.

4. Update `docs/glossary.md` if a new term is introduced.
