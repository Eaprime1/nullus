# Architecture

## System Map

The NULLUS system is organized in layers, from pre-entry to canonical integration:

```
NULLUS / ANTE-ESSE
        ↓
THE — Port of Entry [SPHINCTER — gate mechanism]
        ↓
MAW — Intake Processing
        ↓
System Canon
```

---

## Layer Descriptions

### NULLUS / ANTE-ESSE Layer

The outermost layer contains two elements:

- **NULLUS** — The inversion threshold itself. The entity, the state, the repository. NULLUS presides over the entire architecture as the governing symbolic principle.
- **ANTE-ESSE** — The pre-entry waiting space. Content that has arrived at the system but has not yet crossed the port of entry exists in ANTE-ESSE.

These two elements share the outermost layer because both concern the *pre-canonical* state: NULLUS as the structural principle, ANTE-ESSE as the waiting space for incoming content.

### THE — Port of Entry

THE is the external observation space and the official port of entry. Content passes from ANTE-ESSE into THE when it is ready for canonical consideration. In THE, content is first witnessed by the system.

THE contains **SPHINCTER** — the gate mechanism that controls the opening and closing of the port, regulating flow and maintaining the integrity of the threshold crossing.

### MAW — Intake Processing

After passing through THE (via SPHINCTER), content enters MAW for intake processing. MAW is the rough-intake space: official entry has begun, but full canonical integration is not yet complete. MAW sorts, orients, and prepares content for the final step.

### System Canon

The fully integrated state. Content in System Canon has been:
1. Present in ANTE-ESSE (pre-entry potential).
2. Witnessed in THE (port-of-entry observation).
3. Processed by MAW (intake and orientation).
4. Integrated into the canonical record.

---

## SPHINCTER — Gate/Threshold Logic

SPHINCTER is the mechanism layer within THE. It is not a separate stage in the pipeline but a functional component embedded at the port of entry:

```
THE — Port of Entry Space
  ┌─────────────────────────────────────────────┐
  │  ANTE-ESSE content → [SPHINCTER gate] → MAW  │
  └─────────────────────────────────────────────┘
```

SPHINCTER controls:
- **When** the gate is open (content may pass).
- **How** content is oriented for crossing.
- **The threshold moment** — the exact point of transition.

---

## Integration with the Polarity Model

The integration architecture maps to the polarity model:

| Integration Layer | Polarity Equivalent |
|---|---|
| ANTE-ESSE | Shadow / pre-creation potential |
| THE + SPHINCTER | NULLUS threshold crossing |
| MAW | Post-inversion emergence |
| System Canon | Established polarity state |

Passing through the integration system is structurally analogous to passing through the NULLUS inversion threshold: potential becomes manifest, pre-canonical becomes canonical, shadow becomes form.
